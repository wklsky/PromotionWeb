# 太极馆视觉升级与完善设计方案 V1.0

> 本文档为「外观升级与完善」专项的设计方案，是后续实施的权威依据。
> 状态：已按 P0–P3 全量实施完成（2026-08-13）。CMS `vue-tsc` 类型检查全绿；
> 官网 `nuxt typecheck` 仅余环境层第三方 `.d.mts` 解析噪音（TS 5.4 与 nuxt 工具链 jsx 插件版本不匹配，预存在，无业务代码报错）。
> 关联文档：`design1.md`（总览）、`docs/05-UI视觉设计规范.md`、`docs/09-组件设计文档.md`、`docs/11-CMS后台设计.md`
> 约束基线：技术栈与数据契约以 `taiji-shared` 为单一来源，严禁 `any`、组件不硬编码色彩。

## 0. 背景与目标

当前 monorepo 已具备「东方科技风」的设计骨架：官网有按路由切换的三套主题色（`taiji-shared/src/theme.ts`）、毛玻璃导航、Hero 太极环与卡片系统；CMS 有深色金主题令牌与基础布局。但设计稿（V1.0 总览 §4、§8.3、docs/05）规划的高保真能力大多仍是占位或 TODO：

- 官网 `components/three/TaiChiModel.vue` 只是 Canvas 画一个圆，并非真实 Three.js 太极球；
- `composables/useParallax.ts` 已存在却从未调用，GSAP 依赖已安装但零使用；
- 全站缺少滚动揭示、路由转场、空态/骨架屏，取数期页面是空白；
- CMS 的表格/弹窗/输入仍是 Element Plus 默认观感，无 Dashboard、新闻表无封面/筛选/分页、登录页单薄、侧栏不可折叠。

**目标**：在不改变技术栈与数据契约的前提下，把项目从「有骨架但静态」升级为「沉浸、一致、精致」的品牌数字体验，对齐 docs/05 规范并真正落地 3D 与动效。

## 2. 设计目标与原则

1. **令牌唯一来源**：色彩/圆角/间距只走 `THEME_PALETTES` + `main.css`/`styles.css` 变量，组件零硬编码。
2. **动效降级优先**：3D 与重粒子仅 `min-width:1024px` 且 `prefers-reduced-motion: no-preference` 启用，移动端 CSS 轻动效兜底（守 LCP<2.5s）。
3. **官网/CMS 同语系**：共用金/黑/蓝视觉语言，CMS 不再像「另一个系统」。
4. **可验证**：每阶段有可视化结果与 `pnpm -r typecheck` 门禁。

## 3. 升级蓝图（四层架构）

自底向上，下层为上层基础：

```
页面场景层  Pages & Scenes      Hero 3D 太极 · 三大馆叙事 · 新闻/招聘 · CMS Dashboard
动效交互层  Motion & Interaction GSAP 滚动揭示 · 路由转场 · Hover 微交互 · 3D 渲染   [大幅缺失]
基础组件层  UI Primitives        按钮/卡片/输入 · Element Plus 深度覆写 · 表格/弹窗/标签 [部分缺失]
设计令牌层  Design Tokens        统一色板 · 语义变量 · 深色/浅色双模 · 主题按路由切换   [已有基础]
```

## 4. 升级路线图（四阶段，按投入产出比排序）

### 4.1 P0 · 基础打磨与一致性（通用，官网 + CMS）

- 收口 `main.css`：补语义间距档（`--space-1..6`）、`z-index` 层级表、统一 `transition` 变量。
- 新增通用**空态 / 错误态 / 骨架屏**组件（`SkeletonBlock`、`EmptyState`），应用于 `news`/`[hall]`/`jobs` 与 CMS 列表取数期。
- 统一各页面 `section` 内边距与标题节奏，消除 spacing 漂移。
- 补齐 `focus-visible` 焦点态与跳转锚点（a11y 基础）。
- CMS：`src/styles.css` 深覆 Element Plus（表格斑马纹/表头、输入框聚焦环、按钮圆角、Tag 主题化）。

### 4.2 P1 · 沉浸动效与 3D（官网）

- 落地 `composables/useScrollReveal.ts`（GSAP ScrollTrigger），替代空转的 `.animate-in`；Hero/四大馆/关于页滚动渐入 + 视差（复用 `useParallax.ts`）。
- **真实 Three.js 太极球**：重写 `components/three/TaiChiModel.vue`，渲染阴阳太极 + 随 `--theme-primary` 变化的材质/光照；`defineAsyncComponent` 懒挂载，桌面端启用、移动端降级为现有 CSS 环。
- Nuxt `app.vue` 增加 `pageTransition` + `layoutTransition`（淡入/位移，尊重 reduced-motion）。
- 微交互：按钮磁吸、光标跟随主题色光晕（桌面端、可降级）。

### 4.3 P2 · 内容场景完善（官网 + CMS）

官网：
- 新闻页：分类筛选（接 `NEWS_CATEGORIES`）+ 分页 + 卡片 hover 详情；`useSeoMeta` + JSON-LD（Article）。
- 关于页：数字增长计数（`useCountUp`）+ 发展历程时间轴组件。
- 招聘页：接 `JobController` 真实数据、标签 chips、展开详情。
- 三大馆页：粘性章节导航 + 图片遮罩叙事优化。

CMS：
- 新增 **Dashboard** 概览页（新闻/媒体/招聘计数卡 + 最近动态），登录后默认进入。
- 新闻管理：封面缩略图列、搜索/筛选、分页、编辑（复用新增弹窗）、发布时间列。
- 媒体库：预览弹窗 + 删除。

### 4.4 P3 · CMS 体验升级（CMS）

- Element Plus **深度覆写**：表格行 hover 发光、对话框圆角、Tag 主题化、分页器样式。
- 登录页**分屏布局**：左侧品牌氛围面板（太极环/光晕）+ 右侧表单。
- 侧边栏**可折叠 + 图标化 + 激活指示动画**，移动端抽屉化（`<1024px` 抽屉）。
- 路由级页面转场 + 面包屑基于路由元数据自动生成。

## 5. 共享基础（一次投入，两端复用）

- `taiji-shared` 增补少量 UI 常量（圆角/间距档位），官网与 CMS 就近消费。
- 视觉原语（骨架屏、空态、标签）两端各自就近实现、保持同名同语义，避免重复造轮子又保证风格统一。

## 6. 降级与性能约束

- 3D/GSAP 用 `defineAsyncComponent` 懒加载，SSR 首屏不阻塞。
- 严守 `docs/05 §8.3` 降级规则；Lighthouse 门禁（LCP<2.5s / FID<100ms / CLS<0.1）不放松。
- 图片走 WebP + `<picture>` 响应式源（见 V1.0 总览 §10）。

## 7. 验收标准（每阶段）

- `pnpm -r typecheck` 全绿；`pnpm dev:web` / `pnpm dev:admin` 可运行。
- 视觉回归：关键页面桌面 + 移动端截图对比（防样式回退）。
- 三主题色按路由切换正确、动效降级生效（移动端/reduced-motion 不崩）。
- 新增交互均可键盘可达、对比度达标。

## 8. 风险与对策

| 风险 | 影响 | 对策 |
| ---- | ---- | ---- |
| 3D 致移动端性能劣化 | LCP 超标 | P1 降级策略 + 懒加载 + 性能门禁 |
| Element Plus 深覆样式冲突 | 组件异常 | 仅覆写 CSS 变量与少量 `:deep()`，不改结构 |
| 范围过大导致返工 | 排期顺延 | 严格按 P0→P3 四阶段、每阶段可独立验收 |
| 设计稿与现有 token 不一致 | 视觉漂移 | 一切以 `THEME_PALETTES` + `main.css`/`styles.css` 为准 |

## 9. 已确认事项

- 升级范围：**官网 `taiji-web` + CMS `taiji-admin` 全量**。
- 3D 投入：**实现真实 Three.js 太极球**（桌面端 WebGL，移动端降级）。
- 推进方式：**本方案写入 docs 留存，待确认后逐阶段实施**。
