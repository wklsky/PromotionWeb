## 3. 分层与约定

- **Controller**：仅做参数接收与响应包装，不含业务；标注 `@RequiresRole` 或方法级 `@PreAuthorize`。
- **Service**：业务逻辑；写操作默认软删（`deleted=0` 过滤由 MP 逻辑删除自动完成）。
- **Mapper**：继承 `BaseMapper<T>`，逻辑删除字段 `deleted`，自动注入。
- **Entity/DTO/VO**：与 `taiji-shared` 类型对齐；VO 用 MapStruct 或手动转换，禁止把 Entity 直接序列化外吐。

## 4. 统一响应与异常

- 包装类 `R<T>` = `{ code, message, data }`，与 13 §1 一致。
- 全局异常处理器 `@RestControllerAdvice`：参数校验(400)、未登录(401)、无权限(403)、不存在(404)、限频(429)、系统(500)。
- 错误码表同 13 §10。

## 5. 安全设计（Spring Security + JWT）

### 5.1 认证流程
1. `POST /api/v1/auth/login` → 校验用户名/密码(BCrypt) → 签发 JWT（AccessToken，默认 2h）。
2. 客户端存 token，后续请求头 `Authorization: Bearer <token>`。
3. `JwtAuthenticationFilter` 校验签名与有效期，写入 `SecurityContext`；登出时把 jti 加入 Redis 黑名单（TTL=token 剩余有效期）。

### 5.2 鉴权（RBAC 简版）
- `admin_user.role_id` → `admin_role.name`（`admin`/`editor`）。
- 方法级：`@PreAuthorize("hasRole('ADMIN')")` 保护用户管理；内容维护 `editor` 亦可。
- 接口标注：13 文档中 *(需鉴权)* 的写接口均要求已登录；用户管理类需 `ADMIN`。

### 5.3 密码
- `admin_user.password` 存 BCrypt；初始管理员密文见 `db/seed.sql`，**上线必须改密**。

## 6. Redis 用途

| 用途 | Key 设计 | TTL |
| ---- | -------- | --- |
| 登录限频（contact/apply） | `ratelimit:contact:{ip}` / `ratelimit:apply:{ip}` | 60s，计数达到阈值返 429 |
| JWT 黑名单 | `jwt:blacklist:{jti}` | = token 剩余有效期 |
| 新闻浏览量 | `news:view:{id}` 计数，定时/惰性回写 DB | 可长期，定期聚合 |

## 7. MinIO 媒体库

- 桶 `taiji-media`；上传 `POST /api/v1/media/upload`（multipart），服务端直传 MinIO，返回 CDN/反代地址写入 `media` 表。
- 限制：图片 ≤5MB（png/jpeg/webp），视频 ≤100MB（mp4/webm），见 13 §7。
- 前端 CMS 选封面时读取 `GET /api/v1/media`。

## 8. MyBatis-Plus 配置

- 逻辑删除：`global-config.db-config.logic-delete-field=deleted`，`logic-deleted-value=1`，`logic-not-delete-value=0`。
- 分页：`MybatisPlusInterceptor` 加 `PaginationInnerInterceptor`（MySQL），统一返回 `PageResult`（13 §1）。
- 乐观锁：`news.view_count` 自增可用 `@Version` 或 `UPDATE news SET view_count=view_count+1` 直接更新（并发低可接受）。

## 9. 接口实现映射（与 13 一致）

| 13 接口 | Controller | 说明 |
| ------- | ---------- | ---- |
| `/content*` | ContentController | 企业内容 CRUD |
| `/news*` | NewsController | 新闻 CRUD；详情 +1 浏览量 |
| `/jobs*` | JobController | 招聘 CRUD |
| `/contact`、`/jobs/{id}/apply`、`/leads` | ContactController | 留资/投递 + 限频 |
| `/media*` | MediaController | MinIO 上传/查询 |
| `/auth/*` | AuthController | 登录/登出 |

> 所有 DTO/VO 字段须与 `taiji-shared` 及 13 §2 完全一致，禁止私自增减字段。

## 10. Swagger 配置

- `springdoc-openapi`：`/swagger-ui.html`、`/v3/api-docs`。
- 分组：公开接口（官网读）+ 受保护接口（CMS 写，标注 `@SecurityRequirement`）。
- 生产环境可按 profile 关闭或加 basic auth。

## 12. 开发顺序建议

1. 基础设施：MySQL 建表（`db/init.sql`）+ 初始化数据（`db/seed.sql`）、Redis、MinIO 起服务。
2. 骨架：Spring Boot + MP + Swagger + 全局响应/异常。
3. 安全：JWT + Security + 登录接口。
4. 业务模块：content → news → job → contact → media（按 13 接口逐个实现）。
5. 联调：与 `taiji-web`/`taiji-admin` 通过 `taiji-shared` 契约对齐。

## 13. 与前端契约约束

- 前端 `taiji-web`/`taiji-admin` 依赖 `taiji-shared` 类型；后端 DTO/VO 必须与之逐字段一致。
- 任意一方变更字段，需同步更新 12/13 文档与 `taiji-shared`，PR 中说明。
