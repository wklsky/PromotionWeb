## 1. 组件分层

- **common**：全局通用（Header/Footer/NavDrawer/Button/Tag）
- **sections**：首页分屏区块（Hero/Brand/HallCards）
- **business**：三大馆业务区块
- **three**：3D 专用（TaiChiModel）

## 2. 通用组件

### 2.1 AppHeader
- Props：`navItems: NavItem[]`（默认来自路由表）、`transparent: boolean`
- 行为：滚动超过阈值由透明变实心；当前路由金色下划线。
- 移动端渲染 `NavDrawer`。

### 2.2 AppFooter
- 展示版权、备案、社交链接；数据来自 `company_info` 的 footer section。

### 2.3 NavDrawer
- Props：`open: boolean`；Emits：`update:open`(boolean)
- 移动端汉堡菜单触发的抽屉导航。

### 2.4 BaseButton
- Props：`variant: 'primary' | 'outline'`、`disabled`
- 主按钮金底黑字，次按钮描边。

## 3. 首页区块组件

### 3.1 HeroSection
- 职责：第一屏，承载 3D 太极球 + 标题 + ENTER 按钮。
- 子组件：`TaiChiModel`（异步）。
- 降级：宽度 <1024px 渲染静态海报图。

### 3.2 BrandSection
- 滚动触发：文字渐入（useScrollReveal）、数字增长（useCountUp）。
- 数据：企业简介/核心理念/企业价值（company_info section）。

### 3.3 HallCards
- 三卡片：龙虎/熊猫/鲲鹏，点击 `navigateTo` 对应馆。
- Hover：主题色发光（读取 CSS 变量）。

## 4. 三大馆业务组件（business/）

以龙虎馆为例，其余同构：

### DragonHall

## 5. 3D 系统设计

### 5.1 设计原则
- **唯一重 3D 入口是首页 Hero**（`TaiChiModel.vue`）；三大馆"标志性视觉"用 **CSS / Canvas2D 轻量粒子** 而非独立 Three.js 场景，避免多 WebGL 上下文拖累性能（全站 WebGL context 仅 1 个）。
- **主题色驱动**：3D 材质颜色读取 `taiji-shared` 的 `THEME_PALETTES`，做到"风格不变、仅色彩变"，与 05 §2.2 一致。
- **强制降级**：仅当 `≥1024px && prefers-reduced-motion: no-preference` 才挂载 WebGL；否则渲染静态海报（`<picture>` WebP）。

### 5.2 场景结构（TaiChiModel 内部）
```
Scene
├── Camera(Perspective, fov 45)
├── Lights: AmbientLight + DirectionalLight(主题色 tint)
├── TaiChiGroup (旋转主体)
│   ├── SphereGeometry(基础球, 低模 32×32)
│   ├── 阴阳双鱼 (ShaderMaterial + SDF GLSL)
│   └── 金属外环 TorusGeometry(主题金/白/蓝)
├── ParticleSystem (Points, 800~1200 粒子, 主题色)
└── PostProcessing(可选 Bloom, 仅桌面高级档)
```
- **交互**：鼠标视差由 `useParallax` 返回 `{x,y}` 驱动 `camera.position` 缓动（lerp），不绑定重计算。

### 5.3 逻辑拆分（组件 >100 行必须抽离为 composables）
| 文件 | 职责 |
| ---- | ---- |
| `components/three/TaiChiModel.vue` | 仅挂载/卸载/尺寸自适应，< 100 行 |
| `composables/useThreeScene.ts` | 初始化 Scene/Camera/Renderer/渲染循环，释放资源 |
| `composables/useTaiChiShader.ts` | 阴阳材质 Shader（GLSL 字符串 + uniform 注入主题色） |
| `composables/useParticleField.ts` | 粒子系统生成与主题色绑定 |
| `composables/applyThemeToScene.ts` | 路由切换时把 `THEME_PALETTES.primary/accent` 注入材质 uniform，使 3D 颜色随主题同步 |

### 5.4 资源释放（防 GPU 泄漏，强制）
```ts
onUnmounted(() => {
  cancelAnimationFrame(raf)
  renderer.dispose()
  geometry.dispose()
  material.dispose()
  // 移除 canvas、解绑 resize / parallax 监听
})
```

### 5.5 性能档位（见 05 §5）
| 档位 | 条件 | 策略 |
| ---- | ---- | ---- |
| 高 | ≥1280px, 无 reduce | 全场景 + Bloom + 粒子 1200，DPR≤2 |
| 中 | 768~1279px | 关 Bloom，粒子 600，DPR≤1.5 |
| 低/移动 | <768px 或 reduce | 不挂载 WebGL，显示静态海报图（`<picture>` WebP） |

- 首屏不阻塞 LCP：Three.js 走 `defineAsyncComponent` + 动态 import，用 loading 占位。

### 5.6 TaiChiModel.vue（挂载约定）
- 技术：Three.js + Shader，太极球旋转 + 粒子。
- 加载：`defineAsyncComponent`，桌面端挂载；`<script>` 异步加载不阻塞首屏。
- 卸载：`onUnmounted` 释放 geometry/material/renderer，避免 GPU 泄漏。
- 交互：鼠标视差通过 `useParallax` 驱动相机。

## 6. 组合式函数（composables）

| 函数 | 职责 |
| ---- | ---- |
| `useScrollReveal` | 封装 GSAP ScrollTrigger 渐入 |
| `useParallax` | 鼠标/滚动视差，返回位移 ref |
| `useCountUp` | 数字增长动画 |
| `useTheme` | 按路由设置 `body[data-theme]`，从 `taiji-shared` 的 `ROUTE_THEME_MAP` 取主题并写入 CSS 变量 |
| `useThreeScene` | 初始化/销毁 Three.js 场景与渲染循环 |
| `useTaiChiShader` | 阴阳材质 GLSL 与主题色 uniform 注入 |
| `useParticleField` | 粒子系统生成与主题色绑定 |
| `applyThemeToScene` | 路由切换时同步 3D 材质主题色 |

### useTheme 实现要点
- 在 `layouts/default.vue` 的 `onMounted` 中调用，监听路由变化；
- 进入 `/dragon` → `body.dataset.theme='dragon'`（黑金），`/panda` → `panda`（黑白），`/kunpeng` → `kunpeng`（天蓝白）；
- 主题色板来自 `THEME_PALETTES`，写入 `--theme-primary/--theme-accent/--theme-base/--theme-text`；
- 组件样式只引用 CSS 变量，故**风格不变、仅色彩切换**（见 05 §2.2）；
- 同步调用 `applyThemeToScene(palette)` 将主色/强调色注入 3D 材质 uniform。

## 7. 通用布局组件

### MasonryGrid.vue（瀑布流）
- 用途：新闻中心、案例展示、媒体库、荣誉墙等内容密集型区块的统一瀑布流容器（设计令牌见 05 §6.1）。
- 实现：优先 CSS `column-count` 多列方案（零依赖、`SSR` 友好），卡片 `break-inside: avoid` 避免跨列截断。

```ts
// Props（withDefaults + 工厂函数，避免引用污染）
interface MasonryItem { id: number | string; [key: string]: unknown }
withDefaults(defineProps<{
  /** 瀑布流数据源，泛型卡片数组 */
  items: MasonryItem[]
  /** 各断点列数：base 默认 1、md 默认 2、lg 默认 3 */
  columns?: { base?: number; md?: number; lg?: number }
  /** 列间距（px），默认 16，遵循 8pt 栅格 */
  gap?: number
}>(), {
  items: () => [],
  columns: () => ({ base: 1, md: 2, lg: 3 }),
  gap: 16,
})

// Emits
defineEmits<{
  /** 点击某卡片，回传该卡片数据对象 */
  (e: 'select', item: MasonryItem): void
}>()
```

- 响应式：通过 CSS 媒体查询切换 `column-count`，移动端（<768px）强制单列纵向流。
- 主题：卡片 hover 描边发光读取 `--theme-primary`，随路由主题切换（见 06 `useTheme`）。
- 异步：超长列表（如媒体库 >50 项）需配合虚拟滚动或分页，避免 DOM 过载。

## 7. 组件接口约束（强制）

- 所有 Props 用 `defineProps` + 显式类型；对象/数组默认值用工厂函数。
- 所有 Emits 用 kebab-case，JSDoc 注明回传结构（如 `update:open` 回传 boolean）。
- 组件 `<script>` 业务逻辑 >100 行必须抽离为 `useXxx.ts`。
