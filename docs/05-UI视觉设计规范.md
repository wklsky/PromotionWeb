# 05 太极馆企业宣传网站 · UI 视觉设计规范

> 文档版本：V1.0
> 关联文档：03-网站信息架构IA、07-前端技术架构设计、09-组件设计文档

## 1. 设计语言

新东方科技风：东方韵味 + 现代科技感 + 黑金高级感 + 极简商业设计。
参考：苹果产品展示、华为企业官网、特斯拉、小米生态。

## 2. 色彩体系

### 2.1 基础色（全站）

| 角色 | 色值 | 用途 |
| ---- | ---- | ---- |
| 主黑 | `#080808` | 背景、主文字 |
| 主金 | `#D4AF37` | 强调、分割、点缀 |
| 科技蓝 | `#1677FF` | 链接、交互态 |

### 2.2 各馆主题色（CSS 变量按路由切换）

整体维持「新东方科技风、黑金高级感、极简商业设计」的统一风格；进入不同馆时仅**主题色板切换**，布局与视觉语言不变。

| 馆 | 主调 | 主色(primary) | 强调(accent) | 背景(base) | 文字(text) | 氛围 |
| -- | ---- | ------------- | ------------ | ----------- | ---------- | ---- |
| 龙虎馆 | 黑金 | 金 `#D4AF37` | 金 `#D4AF37` | 黑 `#080808` | 白 `#F5F5F5` | 力量/能量/工业 |
| 熊猫馆 | 黑白 | 白 `#F5F5F5` | 灰白 `#E5E5E5` | 黑 `#080808` | 白 `#F5F5F5` | 生态/智慧/服务 |
| 鲲鹏馆 | 天蓝白 | 天蓝 `#1677FF` | 天蓝 `#1677FF` | 白 `#F5F5F5` | 深蓝 `#0A1A3F` | AI/云/未来 |

> 切换规则：点击对应馆进入路由时，设置 `document.body.dataset.theme = 'dragon' | 'panda' | 'kunpeng'`；全站组件统一引用 CSS 变量（`--theme-primary` / `--theme-accent` / `--theme-base` / `--theme-text`），由 `body[data-theme]` 覆盖，不写死颜色，保证风格统一、仅色彩变化。
>
> 注意：熊猫馆主调为黑底白字（与龙虎一致），鲲鹏馆反转为白底深蓝字，其余视觉元素（卡片、按钮、动效、排版）三馆完全一致。

## 3. 字体规范

| 语言 | 字体栈 | 说明 |
| ---- | ------ | ---- |
| 中文 | `HarmonyOS Sans`, `Source Han Sans`, sans-serif | 首选 HarmonyOS Sans |
| 英文 | `Inter`, `Roboto`, sans-serif | 数字/拉丁文 |

- 字重：标题 600/700，正文 400，辅助 400（灰度）。
- 字号阶梯：display 48+/h1 36/h2 28/h3 22/body 16/sm 14。
- 行高：标题 1.2，正文 1.6。

## 4. 间距与栅格

- 8pt 栅格基准：间距取 8 的倍数（8/16/24/32/48/64）。
- 最大内容宽度：1280px，左右安全边距 ≥24px（移动端 16px）。
- 圆角：卡片 12px，按钮 8px，头像 50%。

## 5. 动效规范

| 类型 | 技术 | 参数 |
| ---- | ---- | ---- |
| 滚动揭示 | GSAP ScrollTrigger | duration 0.8s, ease power2.out |
| 页面切换 | Nuxt Page Transition | fade + 轻微位移 200ms |
| 3D | Three.js Camera | 缓动跟随鼠标（lerp） |
| Hover | CSS transition | 150~250ms |

**降级**：`prefers-reduced-motion: reduce` 或宽度 <768px 时，禁用 3D 与视差，保留基础过渡。

### 5.1 3D 性能档位（与 09 §5.5 一致）
| 档位 | 条件 | 策略 |
| ---- | ---- | ---- |
| 高 | ≥1280px, 无 reduce | 全场景 + Bloom + 粒子 1200，DPR≤2 |
| 中 | 768~1279px | 关 Bloom，粒子 600，DPR≤1.5 |
| 低/移动 | <768px 或 reduce | 不挂载 WebGL，显示静态海报图（`<picture>` WebP） |

### 5.2 3D 主题色联动
3D 材质颜色读取 `taiji-shared` 的 `THEME_PALETTES`，随路由主题切换（见 09 §5.3 `applyThemeToScene`），做到"风格不变、仅色彩变"：
| 馆 | 3D/粒子主色 | 实现 |
| -- | ---------- | ---- |
| 龙虎 | 金 `#D4AF37` | Hero 太极球金环 + 龙虎页 CSS 火焰粒子（金） |
| 熊猫 | 白 `#F5F5F5` | Hero 白环 + 熊猫页灰白粒子 |
| 鲲鹏 | 天蓝 `#1677FF` | Hero 蓝环 + 鲲鹏页星空蓝粒子 |

> 三大馆"标志性视觉"用 CSS / Canvas2D 轻量粒子实现，不新增独立 WebGL 场景，避免多上下文拖累性能。

## 6. 组件视觉令牌（摘要）

| Header | 透明→实心滚动渐变，金色下划线导航 |

## 7. 图片与媒体

- 格式：WebP（兼容回退 jpg/png）；
- 封面比例：新闻 16:9，案例 4:3，荣誉 1:1；
- 图标：线性图标，金色 stroke。
