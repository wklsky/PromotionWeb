# 02 太极馆企业宣传网站 · 产品需求 PRD

> 文档版本：V1.0
> 关联文档：03-网站信息架构IA、05-UI视觉设计规范、12-数据库设计DDD、13-Swagger接口文档

---

## 1. 产品概述

面向企业客户、投资机构、合作伙伴、普通用户、招聘用户的品牌官网，承载展示、导流、传播、合作、招聘五大作用。

## 2. 用户角色与诉求

| 用户 | 核心诉求 | 对应功能 |
| ---- | -------- | -------- |
| 企业客户 | 了解业务、找合作 | 三大馆、联系我们 |
| 投资机构 | 了解实力 | 关于、荣誉、发展历程 |
| 合作伙伴 | 获取合作信息 | 应用/合作案例、联系 |
| 普通用户 | 了解文化 | 首页、关于、新闻 |
| 招聘用户 | 投简历 | 招聘中心、在线投递 |
| 运营人员 | 维护内容 | CMS 后台 |

## 3. 功能需求清单

### 3.1 首页（P0）

| 编号 | 功能 | 说明 | 验收标准 |
| ---- | ---- | ---- | -------- |
| F-HOME-01 | Hero 3D 太极球 | 桌面端 WebGL 旋转 + 粒子/水墨 | 桌面端 60fps，移动端静态降级 |
| F-HOME-02 | 鼠标视差 | 跟随鼠标位移 | 不引起布局抖动（CLS 受控） |
| F-HOME-03 | 品牌介绍屏 | 滚动触发文字渐入/数字增长 | ScrollTrigger 触发准确 |
| F-HOME-04 | 三大馆入口 | 三卡片跳转 | 路由正确、主题色切换 |

### 3.2 关于太极馆（P0）

| 编号 | 功能 | 说明 |
| ---- | ---- | ---- |
| F-ABOUT-01 | 企业介绍 | 图文区块 |
| F-ABOUT-02 | 品牌理念 | 理念陈述 |
| F-ABOUT-03 | 发展历程 | 时间轴组件 |
| F-ABOUT-04 | 组织架构 | 结构图 |
| F-ABOUT-05 | 荣誉资质 | 照片墙 + 数据统计 |
| F-ABOUT-06 | 企业文化 | 文化展示 |

### 3.3 三大业务馆（P0）

| 馆 | 页面区块（自上而下叙事） |
| -- | ------------------------ |
| 龙虎馆（力量型/红黑） | 业务介绍 → 核心能力 → 产品体系 → 行业解决方案 → 客户案例 |
| 熊猫馆（生态型/黑白青绿） | 业务介绍 → 服务体系 → 合作伙伴 → 生态案例 |
| 鲲鹏馆（未来型/蓝紫） | 战略定位 → 未来生态 → 创新能力 → 产业合作 |

各馆主题色通过 CSS 变量按路由切换；标志性视觉：龙虎火焰粒子、熊猫互联网科技风、鲲鹏星空飞行轨迹。

### 3.4 新闻中心（P0）

| 编号 | 功能 | 说明 |
| ---- | ---- | ---- |
| F-NEWS-01 | 新闻列表 | 分页、分类筛选 |
| F-NEWS-02 | 新闻详情 | 富文本渲染、浏览量+1 |
| F-NEWS-03 | 分类 | 企业动态/行业资讯/技术文章 |
| F-NEWS-04 | 搜索 | 按标题/内容模糊检索 |

### 3.5 招聘中心（P0）

| 编号 | 功能 | 说明 |
| ---- | ---- | ---- |
| F-JOB-01 | 岗位列表 | 分页、状态过滤（开放） |
| F-JOB-02 | 职位详情 | 职责/要求/薪资 |
| F-JOB-03 | 在线投递 | 表单提交（姓名/手机/邮箱/简历链接） |

### 3.6 联系我们（P1）

地图/表单/商务合作入口；表单提交至后端留资。

### 3.7 CMS 后台（P0，详见 11-CMS后台设计）

新闻 CRUD、招聘 CRUD、页面内容 CRUD、媒体库、管理员与 RBAC 权限。

## 4. 非功能需求

| 类别 | 要求 |
| ---- | ---- |
| 性能 | LCP<2.5s / FID<100ms / CLS<0.1 |
| SEO | 每页 meta + JSON-LD + sitemap |
| 兼容 | 桌面 Chrome/Edge/Safari；移动 iOS Safari/安卓 Chrome |
| 可访问性 | 基础 a11y（alt、对比度、键盘可达） |
| 安全 | CMS 登录鉴权、接口防刷（投递限频） |

## 5. 验收口径（DoD）

- 所有 P0 功能可在生产环境走通；
- Lighthouse 性能/SEO 分项 ≥ 90；
- CMS 发布内容在官网实时可见；
- 移动端 3D 已降级且无控制台报错。

## 6. 需求优先级说明

- **P0**：首页、关于、三大馆、新闻、招聘、CMS 核心 —— 必须交付；
- **P1**：联系我们表单、媒体库高级能力 —— 应交付；
- **P2**：国际化、AI 导览 —— 本期不做。
