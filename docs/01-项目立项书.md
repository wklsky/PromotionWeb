# 01 太极馆企业宣传网站 · 项目立项书

> 文档版本：V1.0
> 创建日期：2026-08-12
> 文档性质：项目源头文件，界定目标、范围、干系人与里程碑基线

---

## 1. 项目背景

太极馆是一家以东方文化、科技创新、产业生态为核心的综合型企业品牌。当前缺乏统一的对外品牌数字门户，导致：

- 企业实力、三大业务生态（龙虎馆/熊猫馆/鲲鹏馆）缺少系统性展示窗口；
- 新闻、招聘、合作等信息分散，运营效率低；
- 搜索引擎无官方收录入口，品牌曝光受限。

## 2. 项目目标

打造一个**融合东方美学、现代科技、企业实力展示的沉浸式品牌官网**，并具备内容自运营能力。

### 2.1 业务目标

- 建立统一的品牌展示中心、产品业务入口、企业文化传播平台、商务合作窗口；
- 通过 CMS 实现新闻/招聘/页面内容的可运营、可发布；
- 官网内容可被搜索引擎有效收录（SEO 达标）。

### 2.2 体验目标

- 桌面端提供 3D 沉浸视觉（太极球、各馆主题特效）；
- 移动端以响应式 + 轻动效保障性能与可读性；
- 达到华为/小米/苹果级企业官网展示质感。

### 2.3 技术指标

- LCP < 2.5s、FID < 100ms、CLS < 0.1（移动端 4G 弱网）；
- 全站关键页面 SEO meta / 结构化数据 / sitemap 覆盖；
- 支持后续扩展数字展厅、3D 虚拟空间、AI 智能导览。

## 3. 项目范围

### 3.1 范围内（In Scope）

| 模块 | 说明 |
| ---- | ---- |
| 官网 PC 端 | 首页、关于、三大馆、新闻、招聘、联系我们 |
| 官网移动端 H5 | 同一套响应式实现，非独立工程 |
| 3D 视觉系统 | 太极球、龙虎火焰、熊猫生态、鲲鹏星空（桌面端） |
| CMS 后台 | 新闻/招聘/页面内容/媒体库/权限 |
| SEO 体系 | meta / JSON-LD / sitemap / robots |
| 部署与运维 | Docker + Nginx + GitLab CI/CD + 云 |

### 3.2 范围外（Out of Scope · V1.0）

- 数字展厅 / 3D 虚拟空间 / AI 导览（预留扩展能力，不在本期交付）；
- 多语言国际化（V1.0 仅中文，预留 i18n 结构）；
- 用户注册登录与社区功能（仅 CMS 管理员后台）。

## 4. 干系人与角色

| 角色 | 职责 |
| ---- | ---- |
| 产品/项目经理 | 需求把控、排期、验收 |
| UI/UX 设计师 | 视觉规范、原型、动效设计 |
| 前端工程师 | 官网（Nuxt3）+ CMS（Vue3）开发 |
| 后端工程师 | Spring Boot API、数据库、权限 |
| 运维工程师 | 部署、CI/CD、监控 |
| 企业运营 | CMS 内容维护（新闻/招聘） |

## 5. 技术选型基线

- 官网：`Nuxt3 + Vue3 + TypeScript + Three.js + GSAP + TailwindCSS`
- CMS：`Vue3 + Vite + Element Plus + Pinia`
- 后端：`Spring Boot 3 + MyBatis Plus + MySQL + Redis`
- 共享：`taiji-shared`（类型/常量/校验）
- 运维：`Docker + Nginx + GitLab CI/CD + 腾讯云/阿里云`

## 6. 里程碑与周期（总工期 10 周）

| 里程碑 | 时间 | 交付物 |
| ------ | ---- | ------ |
| M1 设计冻结 | W2 | UI 稿 + 数据契约评审通过 |
| M2 基建就绪 | W3 | 两端可启动 + 联调一个接口 |
| M3 官网可走通 | W6 | 全流程页面 + SEO 注入 |
| M4 CMS 可运营 | W8 | 运营可发布内容，官网可见 |
| M5 上线 | W10 | 生产部署 + SEO 提交 |

## 7. 风险与应对（概要）

| 风险 | 应对 |
| ---- | ---- |
| 3D 致移动端性能劣化 | 响应式降级 + 性能门禁 |
| 双前端契约漂移 | taiji-shared 统一 DTO |
| 设计延期阻塞开发 | 先冻结契约与路由 |
| SEO 收录不及预期 | 上线即提交 sitemap |
| 后端不稳阻塞联调 | 前端 Mock 并行 |

## 8. 立项结论

项目目标明确、范围可控、技术路线清晰，准予立项并进入设计阶段。
