| 页面 | 路由 | 文件 | 数据来源 |

| 龙虎馆 | `/dragon` | `pages/dragon.vue` | company_info(section) |

## 3. 导航与全局结构

- 顶部导航（Header）：首页 / 关于 / 龙虎馆 / 熊猫馆 / 鲲鹏馆 / 新闻 / 招聘 / 联系
- 移动端：抽屉式导航（NavDrawer），汉堡菜单触发
- 底部（Footer）：版权、友情链接、备案信息、社交媒体

## 4. 页面区块结构（关键页）

### 首页分屏
1. Hero（3D 太极球）
2. 品牌介绍（滚动渐入 + 数字增长）
3. 三大馆入口卡片

### 关于页纵向流
企业介绍 → 品牌理念 → 发展历程(时间轴) → 组织架构 → 荣誉资质(照片墙) → 企业文化

### 三大馆纵向叙事
见 PRD 3.3，各馆统一"业务→能力/技术→产品/生态→案例/合作"四段式。

## 5. URL 与 SEO 规则

- 语义化英文路径（无中文/无参数堆砌）；
- 详情页使用数字 id（或 slug），配 `useSeoMeta` 注入；
- 生成 `sitemap.xml` 包含所有静态路由与新闻/招聘详情。

## 6. 响应式断点

| 断点 | 设备 | 策略 |
| ---- | ---- | ---- |
| ≥1280px | 桌面 | 完整 3D + 视差 |
| 768~1279px | 平板 | 简化 3D 或静态图 |
| <768px | 手机 | 静态视觉 + CSS 轻动效，3D 不加载 |
