# 太极馆项目部署方案书

> 版本：v1.0 ｜ 适用环境：生产 / 预发 / 本地验证 ｜ 关联文档：docs/07（前端架构）、docs/14（后端设计）、docs/12（数据库）

本文档定义太极馆企业官网 + CMS 后台 + 后端服务的部署架构、构建发布流程、运行配置与运维约定。三端代码位于 pnpm workspace 下的 `apps/`：

- `apps/taiji-web`（前台官网，Nuxt3 SSR）
- `apps/taiji-admin`（CMS 后台，Vue3 + Vite CSR）
- `apps/taiji-server`（后端 API，Spring Boot 3 + Maven）
- `packages/taiji-shared`（共享 TypeScript 契约，构建后被三端引用）

---

## 1. 部署架构总览

### 1.1 拓扑

```
                        ┌──────────────┐
   访客  ──HTTPS──▶     │   Nginx 反向代理 │
   运营  ──HTTPS──▶     │  (80/443)      │
                        └──────┬───────┘
            ┌──────────────────┼──────────────────┐
            │                  │                  │
       ┌────▼────┐        ┌────▼────┐        ┌────▼────┐
       │ taiji-  │        │ taiji-  │        │ taiji-  │
       │ web     │        │ admin   │        │ server  │
       │ :3000   │        │ :5173   │        │ :8080   │
       │ (SSR)   │        │ (静态)  │        │ (API)   │
       └─────────┘        └────┬────┘        └────┬────┘
                               │                  │
                               │          ┌───────┼───────────────┐
                               │          │       │               │
                          ┌────▼───┐  ┌────▼───┐  ┌────▼────┐  ┌────▼────┐
                          │ MySQL  │  │ Redis  │  │ MinIO   │  │ H2(仅local)
                          │ :3306  │  │ :6379  │  │ :9000   │  │
                          └────────┘  └────────┘  └────────┘  └─────────┘
```

### 1.2 流量与角色

| 域名/路径 | 目标 | 说明 |
| --------- | ---- | ---- |
| `https://www.taiji.com` | taiji-web | 官网前台，SSR 利于 SEO |
| `https://cms.taiji.com` | taiji-admin 静态资源 | CMS 后台，纯静态托管 |
| `https://api.taiji.com` | taiji-server `/api` | 后端 API，经 Nginx 反代 |
| `https://cdn.taiji.com` | MinIO（经 Nginx 反代） | 媒体对象公开读取（见 §6） |

> 开发态：前端 `nuxt.config.ts` 与 `vite.config.ts` 已配置 `/api` → `:8080` 代理，无需跨域；生产态统一由 Nginx 收敛到 `api.taiji.com`（见 §5）。

## 3. 构建流程

### 3.1 共享包先行

三端均依赖 `taiji-shared` 构建产物（`dist/`），必须**最先构建**：

```bash
pnpm install
pnpm build:shared        # 等价于 pnpm --filter taiji-shared build
```

### 3.2 前台（taiji-web）

```bash
pnpm dev:web             # 本地开发 (http://localhost:3000)
pnpm --filter taiji-web build      # 产出 .output/
pnpm --filter taiji-web generate   # 纯静态化（可选）
pnpm --filter taiji-web preview    # 预览
```

产物 `.output/` 由 Node 直接托管（`node .output/server/index.mjs`），或交 Nginx 反代。

### 3.3 后台（taiji-admin）

```bash
pnpm --filter taiji-admin build     # vue-tsc 类型检查 + vite 打包到 dist/
```

`dist/` 为纯静态资源，交由 Nginx 托管（`cms.taiji.com`）。

### 3.4 后端（taiji-server）

```bash
cd apps/taiji-server
mvn -q clean package -DskipTests     # 产出 target/taiji-server-0.0.1-SNAPSHOT.jar
```

运行：

```bash
# 本地无依赖验证（H2 + 排除 Redis + MinIO mock）
java -jar target/taiji-server-0.0.1-SNAPSHOT.jar --spring.profiles.active=local

# 生产（依赖经环境变量注入）
DB_USER=xxx DB_PASSWORD=xxx JWT_SECRET=xxx \
MINIO_ACCESS_KEY=xxx MINIO_SECRET_KEY=xxx \
java -jar target/taiji-server-0.0.1-SNAPSHOT.jar
```

### 3.5 CI 推荐顺序

```
pnpm install
  └─ pnpm build:shared
       ├─ pnpm --filter taiji-web build
       ├─ pnpm --filter taiji-admin build
       └─ mvn -f apps/taiji-server package -DskipTests
```

## 4. 配置与密钥管理

### 4.1 后端配置项清单

后端配置见 `application.yml`（默认）与 `application-local.yml`（本地验证）。生产通过**环境变量注入**，禁止明文写入仓库：

| 变量 | 说明 | 默认值 | 生产要求 |
| ---- | ---- | ---- | -------- |
| `DB_USER` | MySQL 用户 | `root` | 专用账号 |
| `DB_PASSWORD` | MySQL 密码 | `root` | 强密码 |
| `JWT_SECRET` | JWT 签名密钥（HS256 ≥ 32 字节） | 本地占位串 | 强随机（见 §4.2） |
| `MINIO_ACCESS_KEY` | MinIO AccessKey | 空（→ mock） | 真实值 |
| `MINIO_SECRET_KEY` | MinIO SecretKey | 空（→ mock） | 真实值 |
| `spring.profiles.active` | 启用 profile | `default` | `prod`（自建） |

> 数据源 URL、Redis host/port、MinIO endpoint 当前写死在 `application.yml`（localhost）。**生产建议**改为 `${MYSQL_HOST}` / `${REDIS_HOST}` 等占位（见 §8 TODO）。

### 4.2 JWT 密钥生成

```bash
# 生成 32 字节 base64 随机串作为 JWT_SECRET
openssl rand -base64 32
```

### 4.3 初始管理员

`db/init.sql` 已写入初始管理员 `admin / 123456`（BCrypt 密文）。**上线前必须修改密码或删除该初始化行**，避免被入侵（见 §7 安全）。

## 5. 生产 Nginx 配置（示例）

```nginx
# api.taiji.com → 后端
server {
    listen 443 ssl;
    server_name api.taiji.com;
    ssl_certificate     /etc/nginx/ssl/api.taiji.com.crt;
    ssl_certificate_key /etc/nginx/ssl/api.taiji.com.key;

    location /api/ {
        proxy_pass http://127.0.0.1:8080;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        # Springdoc 文档如需对外暴露，可单独加 location /swagger-ui/ 并限制内网
    }
}

# www.taiji.com → 前台 SSR（Node 托管）
server {
    listen 443 ssl;
    server_name www.taiji.com;
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}

# cms.taiji.com → 后台静态
server {
    listen 443 ssl;
    server_name cms.taiji.com;
    root /var/www/taiji-admin;
    index index.html;
    location / {
        try_files $uri $uri/ /index.html;   # SPA  history 路由回退
    }
}

# cdn.taiji.com → MinIO 公开读（可选，走 Nginx 反代隐藏 MinIO 端点）
server {
    listen 443 ssl;
    server_name cdn.taiji.com;
    location /taiji-media/ {
        proxy_pass http://127.0.0.1:9000/taiji-media/;
    }
}
```

> 前台与后台开发态靠各自 `proxy` 配置连 `:8080`；生产态统一经 `api.taiji.com` 收敛，前端 `baseURL: '/api'` 无需改动（同源部署或前端再配 Nginx 代理皆可）。

## 6. 媒体存储（MinIO）部署

### 6.1 真实模式

1. 部署 MinIO，创建 bucket `taiji-media`。
2. 注入 `MINIO_ACCESS_KEY` / `MINIO_SECRET_KEY`，`minio.mock=false`（默认）。
3. 后端 `MediaServiceImpl.upload` 直传 MinIO，返回 `endpoint + bucket + objectName`。
4. 生产 `endpoint` 指向 `cdn.taiji.com`（经 §5 Nginx 反代），对外只暴露 CDN 域名（docs/14 §6）。

### 6.2 占位模式（mock）

未配置 MinIO 凭据时，上传自动回退 `mock://taiji-media/<uuid>-<name>` 占位 URL 并落库（docs/14 §6）。**该模式仅用于本地验证 / 无对象存储联调，禁止用于生产**。

## 7. 安全约定

| 项 | 要求 |
| ---- | ---- |
| JWT | 密钥经 `JWT_SECRET` 强随机注入；退出登录写入 Redis 黑名单；默认 2h 过期 |
| 初始管理员 | `db/init.sql` 的 `admin/123456` 上线前必须改密或删除初始化行 |
| 公开接口 | 仅 `GET /api/news`、`GET /api/content/**`、`GET /api/jobs`、`GET /api/jobs/*`、`GET /api/media`、联系/投递 POST 免登录（SecurityConfig 放行清单） |
| 写操作 | 新闻/媒体/内容增删改需携带 `Authorization: Bearer <token>`，否则 401 |
| 数据库 | 业务库仅内网可达，不暴露公网 3306 |
| springdoc | `/swagger-ui.html` 生产建议限制内网或关闭 |
| HTTPS | 全站强制 TLS，Nginx 终止 |

## 8. 容器化部署（可选）

### 8.1 后端 Dockerfile（示例）

```dockerfile
FROM eclipse-temurin:17-jdk AS build
WORKDIR /app
COPY apps/taiji-server /app
RUN mvn -q clean package -DskipTests

FROM eclipse-temurin:17-jre
WORKDIR /app
COPY --from=build /app/target/taiji-server-0.0.1-SNAPSHOT.jar app.jar
EXPOSE 8080
ENTRYPOINT ["java","-jar","app.jar"]
```

### 8.2 前端镜像

- taiji-web：`node:20-alpine` 构建后，运行 `.output`（或 nginx 托管）。
- taiji-admin：`node:20-alpine` 构建 `dist/`，用 `nginx:alpine` 托管静态。

### 8.3 编排（docker-compose 示例）

```yaml
services:
  server:
    build: ./apps/taiji-server
    environment:
      DB_USER: ${DB_USER}
      DB_PASSWORD: ${DB_PASSWORD}
      JWT_SECRET: ${JWT_SECRET}
      MINIO_ACCESS_KEY: ${MINIO_ACCESS_KEY}
      MINIO_SECRET_KEY: ${MINIO_SECRET_KEY}
    depends_on: [mysql, redis, minio]
  mysql:   { image: mysql:8.0, environment: { MYSQL_DATABASE: taiiji } }
  redis:   { image: redis:7-alpine }
  minio:   { image: minio/minio, command: server /data }
  nginx:   { image: nginx:alpine, ports: ["80","443"], volumes: [./nginx:/etc/nginx/conf.d] }
```

> 注：当前仓库未提供 Dockerfile / compose 文件，以上为方案建议，落地时按需创建。

## 11. 回滚与监控

- **回滚**：后端 jar 保留上一版本，`java -jar` 切换即可；前端静态资源按版本目录或 CDN 版本号回退。
- **健康检查**：后端 `/actuator/health`（需在 pom 增加 `spring-boot-starter-actuator`，当前未引入，见 §12 TODO）。
- **日志**：后端 `logs/`；Nginx `access.log` / `error.log`；建议接入集中日志（ELK / Loki）。
- **监控**：MySQL / Redis / MinIO 存活探针；API 错误率告警。
