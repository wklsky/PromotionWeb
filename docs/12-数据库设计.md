# 12 太极馆企业宣传网站 · 数据库设计

> 文档版本：V1.1（与 13-Swagger 双向验证一致）
> 关联文档：02-产品需求PRD、11-CMS后台设计、13-Swagger接口文档
> 建表脚本：`db/init.sql`（MySQL 8.0+，含初始化数据）

---

## 1. 设计原则

- 官网内容由 CMS 驱动，数据库即内容契约；
- 统一审计字段：`create_time`（创建）、`update_time`（更新，自动）、`create_by`（创建人）；
- 统一软删除：`deleted` TINYINT 默认 0；所有查询默认 `deleted=0`；
- SEO 字段随内容存储，官网 `useSeoMeta` 直接读取；
- 枚举值用 STRING（可读性）或 TINYINT + 字典，前后端共用 `taiji-shared` 常量；
- 时间统一 `DATETIME`，应用层格式化 `yyyy-MM-dd HH:mm:ss`。

## 2. 核心数据表

### 2.1 company_info（企业内容）
```sql
CREATE TABLE company_info (
  id          BIGINT       PRIMARY KEY AUTO_INCREMENT,
  section     VARCHAR(32)  NOT NULL COMMENT '区块标识 intro/philosophy/history...',
  title       VARCHAR(128) NOT NULL,
  content     LONGTEXT     COMMENT '富文本',
  cover       VARCHAR(512) COMMENT '封面URL',
  seo_title   VARCHAR(128),
  seo_keywords VARCHAR(255),
  seo_desc    VARCHAR(512),
  sort        INT          DEFAULT 0,
  status      TINYINT      DEFAULT 1 COMMENT '0草稿 1发布',
  create_by   VARCHAR(64),
  create_time DATETIME     DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  update_time DATETIME     DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  deleted     TINYINT      DEFAULT 0 COMMENT '软删除'
) COMMENT='企业内容表';
```

### 2.2 news（新闻）
```sql
CREATE TABLE news (
  id           BIGINT      PRIMARY KEY AUTO_INCREMENT,
  title        VARCHAR(128) NOT NULL,
  category     VARCHAR(32)  NOT NULL COMMENT '企业动态/行业资讯/技术文章',
  content      LONGTEXT,
  cover        VARCHAR(512),
  author       VARCHAR(64),
  seo_title    VARCHAR(128),
  seo_keywords VARCHAR(255),
  seo_desc     VARCHAR(512),
  status       TINYINT     DEFAULT 1 COMMENT '0草稿 1发布',
  view_count   INT         DEFAULT 0,
  publish_time DATETIME,
  create_time  DATETIME     DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  update_time  DATETIME    DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  deleted      TINYINT     DEFAULT 0 COMMENT '软删除'
) COMMENT='新闻表';
```

### 2.3 job（招聘）
```sql
CREATE TABLE job (
  id           BIGINT      PRIMARY KEY AUTO_INCREMENT,
  position     VARCHAR(64) NOT NULL COMMENT '职位名',
  department   VARCHAR(64),
  city         VARCHAR(32),
  description  LONGTEXT    COMMENT '职责',
  requirement  LONGTEXT    COMMENT '要求',
  salary       VARCHAR(32),
  type         VARCHAR(16) DEFAULT '全职' COMMENT '全职/实习',
  status       TINYINT     DEFAULT 1 COMMENT '0关闭 1开放',
  publish_time DATETIME,
  create_time  DATETIME     DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  update_time  DATETIME    DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  deleted      TINYINT     DEFAULT 0 COMMENT '软删除'
) COMMENT='招聘表';
```

### 2.4 contact_lead（联系/投递留资）
```sql
CREATE TABLE contact_lead (
  id          BIGINT PRIMARY KEY AUTO_INCREMENT,
  name        VARCHAR(64) NOT NULL,
  phone       VARCHAR(32) NOT NULL,
  email       VARCHAR(128),
  type        VARCHAR(16) DEFAULT 'contact' COMMENT 'contact/job',
  ref_id      BIGINT COMMENT '关联 job.id（投递时）',
  resume_url  VARCHAR(512),
  message     VARCHAR(1024),
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  deleted     TINYINT DEFAULT 0 COMMENT '软删除'
) COMMENT='留资表';
```

### 2.5 media（媒体库）
```sql
CREATE TABLE media (
  id          BIGINT PRIMARY KEY AUTO_INCREMENT,
  url         VARCHAR(512) NOT NULL COMMENT 'CDN地址',
  name        VARCHAR(255) NOT NULL COMMENT '原始文件名',
  type        VARCHAR(16)  NOT NULL COMMENT 'image/video',
  size        BIGINT       COMMENT '字节',
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  deleted     TINYINT DEFAULT 0 COMMENT '软删除'
) COMMENT='媒体库表';
```

### 2.6 admin_user / admin_role（CMS 权限，简版 RBAC）
```sql
CREATE TABLE admin_role (
  id   BIGINT      PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(32) NOT NULL COMMENT 'admin/editor',
  desc VARCHAR(64) COMMENT '描述',
  UNIQUE KEY uk_name (name)
);
CREATE TABLE admin_user (
  id          BIGINT PRIMARY KEY AUTO_INCREMENT,
  username    VARCHAR(64) UNIQUE NOT NULL,
  password    VARCHAR(128) NOT NULL COMMENT 'BCrypt',
  role_id     BIGINT NOT NULL,
  status      TINYINT DEFAULT 1 COMMENT '0禁用 1启用',
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP,
  deleted     TINYINT DEFAULT 0,
  KEY idx_role (role_id),
  CONSTRAINT fk_user_role FOREIGN KEY (role_id) REFERENCES admin_role (id)
) COMMENT='管理员表';
```

> 初始化数据见 `db/init.sql`：预置 `admin`/`editor` 两角色、初始管理员（账号 `admin`，**上线必须改密**）。

## 3. 索引建议

| 表 | 索引 | 用途 |
| -- | ---- | ---- |
| company_info | `idx_section (section)` | 按区块查询（关于页/各馆） |
| company_info | `idx_status_sort (status, sort)` | 已发布内容排序 |
| news | `idx_category_status (category, status)` | 分类+状态筛选 |
| news | `idx_publish (publish_time)` | 时间排序 |
| job | `idx_status (status)` | 仅开放岗位 |
| job | `idx_publish (publish_time)` | 时间排序 |
| contact_lead | `idx_type (type)`、`idx_ref (ref_id)` | 投递查询 |
| media | `idx_type (type)` | 媒体类型筛选 |
| admin_user | `uk_username`、`idx_role (role_id)` | 登录/角色过滤 |

## 4. 与接口/前端的契约（双向验证）

> 本节与 `docs/13-Swagger接口文档.md` 逐字段对齐，修改任一侧须同步另一侧的 `taiji-shared` 类型。

| 表 | 对应接口 | VO/DTO |
| -- | -------- | ------ |
| company_info | `/content*` | CompanyInfoVO / CompanyInfoDTO |
| news | `/news*` | NewsListVO / NewsDetailVO / NewsDTO |
| job | `/jobs*` | JobListVO / JobDetailVO / JobDTO |
| contact_lead | `/contact`、`/jobs/{id}/apply`、`/leads` | ContactLeadVO |
| media | `/media*` | MediaVO |
| admin_user/role | `/auth/*` | LoginResultVO |

- **分页结构**：列表接口统一返回 `PageResult<T> = { list, total, page, size, pages }`，与 13 §1 一致。
- **软删除**：所有查询 `WHERE deleted = 0`；DELETE 接口执行软删（`deleted=1`）。
- **枚举一致**：`category/type/status/role/media.type` 取值与 13 §9 枚举常量完全相同。
- **响应包装**：`{ code, message, data }`，错误码见 13 §10。

## 5. 表字段 ↔ 接口字段映射核对（防漂移）

| 接口字段 | 表字段 | 备注 |
| -------- | ------ | ---- |
| CompanyInfoVO.id | company_info.id | — |
| CompanyInfoVO.section | company_info.section | 枚举内取值 |
| NewsListVO.viewCount | news.view_count | 详情接口 +1 |
| JobDetailVO.description | job.description | 职责 |
| ContactLeadVO.refId | contact_lead.ref_id | 驼峰↔下划线 |
| MediaVO.url | media.url | CDN 地址 |
| LoginResultVO.role | admin_role.name | 登录返回角色名 |
