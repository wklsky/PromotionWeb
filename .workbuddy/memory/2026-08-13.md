## 代码检查与问题修复（Craft · 资源泄漏专项）

用户要求「检查当前代码，修复问题代码」。本轮聚焦运行时资源泄漏与契约安全，逐项核查官网 3D/动效与 CMS 全部改动：

### 确认的「非 bug」（避免误改）
- 后端 `update` 用 `updateById(job)`：MyBatis-Plus 全局配置未改 `field-strategy`，默认 `NOT_NULL` → null 的 `createTime`/`publishTime`/`updateTime` 不写入 SET，不会清空历史字段（无数据覆盖风险）。
- 所有 entity(`News`/`Job`/`Media`) 均 `@TableId(type=IdType.AUTO)` → `create` 返回 `getId()` 正确。
- `useParallax` SSR 安全（仅 `onMounted`/`onUnmounted` 访问 `window`）；`useTheme` 写入 `--theme-primary` → 3D 球主题色随路由切换正确。
- CMS 契约与后端一致：`vue-tsc --noEmit` 全绿；`node:test` 业务逻辑 **11/11 通过**。

### 修复的真实 bug
- **[Bug·高] `TaiChiModel.vue` GPU 资源泄漏**：`onBeforeUnmount` 仅 `renderer.dispose()`，未释放几何体/材质/Canvas 贴图 → 每次离开首页泄漏 WebGL 资源。修复：把 `sphere`/`wire`/`tex` 提升为外层变量，卸载时释放 `geometry`+`material`(数组收窄 `Array.isArray` 逐一 `dispose`)+`texture`，并 `forceContextLoss()`。
- **[Bug·中] `CountUp.vue` 观察器/补间泄漏**：`onMounted` 创建 `IntersectionObserver` 与 `gsap.to` 补间，但未在卸载时清理。修复：保存 `io`/`tween` 引用，并在 `onBeforeUnmount` 中 `disconnect()`+`kill()`。
